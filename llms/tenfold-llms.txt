# Tenfold

> Tenfold (a LivePerson company) is a computer-telephony integration (CTI)
> platform — the "Customer Experience Cloud" — that connects phone systems and
> contact-center platforms with CRM and support systems. The REST API originates
> and queries calls, controls call recording, manages users and organizations,
> reads and writes CRM records, and returns call analytics, transcripts, and
> keyword extraction. Generated by the API Evangelist enrichment pipeline.

## APIs

- [Tenfold API v2](https://apidocs.tenfold.com/): REST API — base URL https://api.tenfold.com — OAuth 2.0 and JWT bearer authentication.

## Notes

- API v1 (/api/v1) is deprecated; use v2 (/v2).
- Real-time call events (queued, ringing, in-progress, finished) are delivered via webhook.
- Pagination: page (default 0) and pageSize (v2 max 500).
- No idempotency-key header or published rate-limit policy documented.
